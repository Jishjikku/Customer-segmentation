# Customer Segmentation

## Overview
This sample project groups customers into segments using K-Means clustering.

## Dataset
`customer_data.csv` is a small demonstration dataset containing customer age, annual income, and spending score. It is sample data, not real customer records.

## Run
```bash
pip install -r requirements.txt
python customer_segmentation.py
```

The script saves `segmented_customers.csv` and `customer_segments.png`.
